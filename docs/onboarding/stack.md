# Stack

roots:
- engine: plugins/ai-coach-core/hooks (library + CLI + every hook — the only runtime area)
- skills: plugins/*/skills (markdown, no runtime)

build_cmd: none (zero-dependency Node) · test_cmd: `node plugins/ai-coach-core/hooks/engine.test.js` and `hooks.test.js`
lint_cmd: none · docs_dir: docs/

conventions:
- Node ≥ 22.5, `node:sqlite`, zero runtime dependencies (README "Install")
- storage: SQLite per project at `~/.ai-coach/projects/<slug>/coach.db` + user scope `user.db` (schema.sql:10-106, user-schema.sql:8-26)
- engine is both library and CLI: hooks `require('./engine.js')`, skills call `node ~/.ai-coach/bin/engine.js <subcommand>` (engine.js:89 `bootstrap()` keeps that copy current)
- all hooks wired in one file: plugins/ai-coach-core/hooks/hooks.json — feature plugins ship zero hooks
- tests: no framework, throwaway DBs, `assert` + spawnSync ([[start-here]])
- releases: git tags `{plugin}--v{version}`, one focus per release

See [[01-skills-only-plugins]] and [[02-hook-contract]] for the two patterns everything follows.
