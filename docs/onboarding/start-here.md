# Start here

## Setup → first run

Requires Node ≥ 22.5 (`node:sqlite`). No install step, no dependencies.

```bash
git clone git@github.com:MohammedMoataz/ai-coach.git
node plugins/ai-coach-core/hooks/engine.test.js   # engine suite — expect ALL PASS
node plugins/ai-coach-core/hooks/hooks.test.js    # hook binaries against fake stdin — ALL PASS
```

Both suites use throwaway databases via `AICOACH_DB` (hooks.test.js:11-18) — nothing touches your
real `~/.ai-coach/`.

## Your first task

Add one detector fixture: pick a prompt shape, add a case to the v0.2.0 section of
`plugins/ai-coach-core/hooks/engine.test.js`, run the suite. Touches one file, teaches you the
fixture discipline and the detector table (`PROMPT_RULES` in engine.js) at once.

## Core flows

1. **Session start** — Claude Code fires SessionStart → `hooks/session-start.js` resolves the
   project DB, injects the ranked memory brief (engine.js:449 `brief()`), one coach line
   (engine.js:543 `coachLine()`).
2. **Tool call guarded** — PreToolUse → `hooks/guard.js`: real credentials block (exit 2,
   guard.js:52), secret-ish payloads ask (guard.js:32).
3. **Fetched content checked** — PostToolUse on WebFetch/WebSearch/Read → `hooks/spotlight.js`
   warns both audiences on injection markers (spotlight.js:45,49), never blocks.

## Glossary

- **brief** — the ≤4K-char memory injection at session start; every line says why it ranked.
- **coach line** — the single highest-priority true observation in the brief, or silence.
- **correction** — a recorded moment a failure surfaced; the richest signal in a session.
- **seed** — `.ai-coach/team-seed.jsonl`, the git-transported memory handoff.
- **spotlight** — the injection check on content coming back from the world.
- **tenant** — one project's SQLite database under `~/.ai-coach/projects/<slug>/`.
