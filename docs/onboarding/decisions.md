# Decisions (inferred)

Reverse-engineered from the code and changelog, not minutes from a meeting — treat each as a
hypothesis with evidence.

### D1 — Only core wires hooks (INFERRED)
**Context**: cross-plugin hook ordering is undocumented in Claude Code.
**Decision**: every hook lives in ai-coach-core/hooks/hooks.json; the five coach plugins ship
skills only (their plugin.json declare no hooks).
**Consequences**: a feature needing hook-time behavior lands in core and forces a core release —
the dependency tilde (`~0.x.0`) then forces version bumps on every sibling (CHANGELOG v0.3.0).

### D2 — The engine lives at ~/.ai-coach/, not in the plugin (INFERRED)
**Context**: `${CLAUDE_PLUGIN_ROOT}` is documented as ephemeral; sibling plugins cannot reach it.
**Decision**: core copies engine.js to `~/.ai-coach/bin/` on session start (engine.js:89).
**Consequences**: skills call a stable path on every platform; the copy must be kept current —
that's `bootstrap()`'s diff-then-refresh job.

### D3 — Zero runtime dependencies (INFERRED)
**Context**: hooks run on every session of every teammate; an npm install step would be a
support burden and an attack surface.
**Decision**: `node:sqlite`, `node:crypto`, nothing else (no package.json dependencies).
**Consequences**: Node ≥ 22.5 floor; features that would need a library (OCR, AST parsing) are
delegated to partner tools instead ([[../onboarding/index|see /partners]]).

### D4 — Warn-only for inbound content, block for outbound secrets (INFERRED)
**Context**: published injection-guardrail bypass rates are 20–72%; false-positive blocks on
fetched articles would be constant.
**Decision**: guard.js may exit 2 (block) on real credentials leaving; spotlight.js only ever
warns on content coming in (spotlight.js:45-49, CHANGELOG v0.3.0).
**Consequences**: the injection check must never be sold as protection — every warning carries
its own low-confidence caveat.
