# Pattern: the hook contract

## Quick reference
A hook is a Node script reading JSON on stdin, wired in core's hooks.json with a `statusMessage`,
that can never break a session.

## Pattern template
```js
if (process.env.AICOACH_INNER) process.exit(0); // spawned children: no recursion
let raw = ''; process.stdin.on('data', d => raw += d);
process.stdin.on('end', () => {
  try { /* work */ } catch (err) {
    try { require('./engine.js').log('<hook>', err); } catch { /* never block */ }
  }
  process.exit(0);
});
```

## CRITICAL rules
- NEVER let a hook exit non-zero on its own failure — fail open, log to `~/.ai-coach/log.jsonl`
  (session-start.js:75-78). The only deliberate non-zero is guard.js's block, exit 2 (guard.js:52).
- NEVER merge the two channels: `systemMessage` talks to the user, `additionalContext` to the
  model (spotlight.js:45,49) — a prompt critique injected beside the prompt steers answers into
  meta-commentary.
- ALWAYS set `statusMessage` in hooks.json (hooks.json:13-21) or the /hooks picker shows raw node
  commands.

## DO / DON'T
- DO: guard every spawned `claude -p` with `AICOACH_INNER=1` — without it SessionEnd loops forever.
- DON'T: read repo-controlled files with bare readFileSync — use `engine.safeRead` (engine.js:34),
  which refuses symlinks and caps size.
