# Pattern: skills-only feature plugins

## Quick reference
Adding a coach feature = a new plugin with `.claude-plugin/plugin.json` + `skills/<name>/SKILL.md`.
Zero hooks, zero userConfig, one dependency on ai-coach-core.

## Pattern template
```json
{ "name": "<x>-coach", "version": "0.1.0",
  "dependencies": [{ "name": "ai-coach-core", "version": "~0.4.0" }] }
```
SKILL.md frontmatter: trigger-tail `description` (short — always-on cost tracks its length),
`disable-model-invocation: true` for anything with side effects, `model: haiku` + `effort: low`
only when the work is CLI-and-format.

## CRITICAL rules
- NEVER add a hooks.json to a feature plugin — hook ordering across plugins is undocumented (D1).
- NEVER declare userConfig outside core — the user must be prompted once, not five times.
- Keep the skill description short; it is the only always-on token lever (README "What ships").

## DO / DON'T
- DO: call the engine as `node "$HOME/.ai-coach/bin/engine.js" <cmd>` — the stable copy.
- DON'T: reference `${CLAUDE_PLUGIN_ROOT}` of a sibling plugin — blocked by the platform.
