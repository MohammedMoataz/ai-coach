# /vault — make ./docs a vault, break nothing

Obsidian needs no setup: a vault is any folder, and every note here is plain markdown that reads
fine in a terminal, in a pull request, and to an agent. This skill only adds what a vault needs to
be *navigable* — one hub, two folders, and one page of conventions — then links whatever
`/investigation-coach:onboard`, `/atlas-coach:ingest` and `/atlas-coach:research` already wrote.

Nothing here is clever, which is the point. It runs before `/strategy-coach:blueprint` so that
skill has somewhere to write, and it is safe to re-run.

`ENGINE` means `node "$HOME/.ai-coach/bin/engine.js"`, or
`node "$env:USERPROFILE\.ai-coach\bin\engine.js"` in PowerShell.

## Steps

1. **Look before writing** — list `docs/`. Note which of these exist: `00-index.md` (atlas's
   ingest index), `onboarding/index.md`, `study/index.md`, `research/`, and any `home.md`. With
   `--dry-run`, do steps 2-6 as a report only and write nothing.
2. **Folders** — create `docs/business/` and `docs/features/` if absent. Empty directories do not
   survive git, so each gets its hub note in step 3; no `.gitkeep`.
3. **The hub** — write `docs/home.md`: the vault's entry point, MOC pattern, links only, one line
   of context each. It links *to* `00-index.md`; it never edits it. Load
   `references/layout.md` for the exact body.
4. **Conventions** — write `docs/conventions.md`: the wikilink rule, the frontmatter allowed, the
   generated-marker rule, and the filename sanitization. This is the page a teammate reads before
   hand-editing a generated note. Body in `references/layout.md`.
5. **Gitignore** — if `.gitignore` lacks it, append `.obsidian/workspace*` and
   `.obsidian/cache`. Obsidian's own config is worth committing; its per-machine window layout is
   not. Append only — never rewrite or reorder that file.
6. **Report** — three lists: created, linked, and **skipped because hand-written**. The third list
   matters most: say the filename and that it has no `/strategy-coach:` marker, so the user knows
   why it was left alone rather than assuming it was missed.
7. **Remember** — `ENGINE add reference "docs/ is an Obsidian vault; hub at docs/home.md, business notes in docs/business/, feature specs in docs/features/" 0.75`

## Rules

- **Never create a `.obsidian/` directory.** Obsidian writes its own on first open, and a
  hand-made one with the wrong schema version is worse than none.
- **Never overwrite a file that does not start with a `> Generated by /strategy-coach:` line.**
  No marker means a person wrote it. Report it as skipped and move on.
- **`docs/00-index.md` belongs to `/atlas-coach:ingest`.** Link it, never touch it.
- **Every generated note keeps at least one outbound wikilink**, so nothing orphans in the graph
  view.
- **Never rename or move an existing file.** A vault is a link graph; a rename breaks links this
  skill cannot see.
- Filenames sanitize `* " \ / : | ?` to `-`, with the real name kept as an `aliases:` entry.
