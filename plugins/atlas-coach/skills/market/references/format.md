# docs/market/&lt;slug&gt;.md

Load when writing. One file per market or competitive question, refreshed in place — never forked
into `-v2`. Starts with:

```
---
tags: [...]
---
> Generated by /atlas-coach:market · YYYY-MM-DD
```

Frontmatter first, marker second: Obsidian parses frontmatter only when it starts at byte 0, so a
marker line above it discards the note's tags. A note with no frontmatter keeps the marker on
line 1.

Ordered so the decision comes first. Anyone reading past the second section is doing so by choice.

## Refresh behaviour

`--refresh` re-fetches and rewrites in place, keeping the same path. Move superseded findings into a
`## Superseded` list with both dates rather than deleting them — a competitor that *added* the
thing you built a strategy around is the single most important diff this document can show, and
deletion hides it.

A file whose marker line was removed is hand-owned: read it, cite it, do not rewrite it.
