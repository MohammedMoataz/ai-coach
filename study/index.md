# Studying AI Coach

## Threshold concepts

1. **Everything routes through one engine.** Hooks `require` it; skills shell out to a stable
   copy of it. Once you see engine.js as both library and CLI, every plugin reads as a thin
   client. Read: plugins/ai-coach-core/hooks/engine.js (exports at the bottom).
2. **A hook may warn, log, or stay silent — it may never break a session.** Every hook is wrapped
   fail-open; the sole deliberate non-zero exit is the secrets guard's block. Once internalized,
   the error handling everywhere stops looking paranoid and starts looking like the contract.
3. **Data has a privacy direction.** Signals, counts and names travel (seeds, --team pooling);
   text never does (prompts, corrections, finding evidence). Every schema and export decision
   follows from that one rule.

## Discovered areas

This project's architecture yields one runtime area: **engine/** (the core library-and-CLI plus
its hooks — everything else is markdown skills). No UI area — it ships no frontend. That is a
fact of the architecture, not an omission.
